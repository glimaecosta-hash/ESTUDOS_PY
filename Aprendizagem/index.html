Aprendizagem de Python

No Python, a indentação (espaços ou tabulações no início de uma linha) é utilizada para delimitar blocos de código. Diferente de outras linguagens que utilizam chaves ou palavras-chave, o Python utiliza a indentação para determinar o escopo das declarações. Por exemplo: 

            if condition:
                # bloco de código se a condição for verdadeira
                instrução1
                instrução2
            else:
                # bloco de código se a condição for falsa
                instrução3
                instrução4

E inportante ter uma indentação consistente em todo o código.

Sensibilidade a maiúsculas e minúsculas

Python distingue entre letras maiúsculas e minúsculas. Por exemplo, "variavel" e "Variavel" são consideradas variáveis diferentes.

Ponto e vírgula

Diferente de outras linguagens, o Python não requer o uso de ponto e vírgula (;) ao final de cada instrução. No entanto, se você desejar escrever várias instruções em uma única linha, pode separá-las com um ponto e vírgula. Por exemplo: 

            instrucao1; instrucao2; instrucao3

Uso parenteses

São utilizados para agrupar expressões e controlar a ordem de avaliação dos operadores. 

             resultado = (a + b) * c

Tipos de Dados Básicos

Inteiros (int)

São numero inteiros onde não tem a parte decimal. E não precisa de um tipo especial para representá-los. 

            idade = 25
            quantidade = 10

Flutuantes (float)

São números que possuem parte decimal. Em Python, os números flutuantes são representados pelo tipo float. 

            preço = 19.99
            altura = 1.75

Cadeias de texto (string)

São cadeia de texto que são representadas por aspas duplas ("") ou simples (''). Alem de serem usadas para armazenar textos, strings também podem ser utilizadas para realizar operações como concatenação e formatação. 

        nome = "João"
        saudacao = 'Olá, ' + nome + '!'

Booleanos (bool)

São valores logicos, utilizados para false ou true, pode ser ver comumente utilizados em expressões condicionais. 

            e_maior_de_idade = True
            tem_permissao = False

Os valores booleanos em Python começam com uma letra maiúscula: True e False

Variáves

As variáveis são conteines que permite armazenar e manipular dados durante a execução de um programa. Pode dar nomes variais para identificá-las. Em python não e necessária a declaração de tipo, pois o python ja identifica o tipo automaticamente. Pois ele e é uma linguagem de tipagem dinâmica: o tipo é associado ao valor, não à variável em si

Declaração e Atributo de Variaveis

A variaveis são conteiner qualquer que permite armazenar e manipular dados durante a execução de um programa. E para declarar elas utlizamos o operador de atribuição (=), e colcoa o nome da variavel a esquerda e o valor a direita. 

      idade = 25
      nome =" giovana"
      altura = 1.75
      e_estudante = True

Você também pode atribuir o mesmo valor a várias variáveis em uma única linha usando o operador de atribuição múltipla: 

       a = b = c = 10

Neste caso, as variáveis a, b e c terão o valor 10

Regras para nomear variáveis

Ao nomear variáveis, é importante seguir algumas regras:

  • Os nomes das variáveis só podem conter letras (a-z, A-Z), números (0-9) e sublinhados (_). Não podem começar com um número
  • Não se pode usar palavras-chave reservadas do Python como nomes de variáveis (por exemplo, if, else, for, while, etc.).
  • O Python diferencia maiúsculas de minúsculas, então nome e Nome são variáveis diferentes.
  • Recomenda-se usar nomes descritivos para as variáveis, que indiquem claramente seu propósito: nome, idade, total_vendas, etc.

Operadores

São simbolos que permite realizar operações em valores e variáveis. Em Python, existem vários tipos de operadores, como operadores aritméticos, relacionais e lógicos.

Operadores Aritméticos

São operados matematico para operações matematica simples como adição, subtração, multiplicação e divisão.

  • Adição: +
  • Subtração: -
  • Multiplicação: *
  • Divisão: /
      a = 10
      b =3

      soma = a + b   # 13
      subtracao = a - b    # 7
      multiplicacao = a * b    # 30
      divisao = a / b   # 3.333333333
      divisao_inteira = a // b   # 3
      modulo = a % b   # 1
      exponenciacao = a ** b   # 1000
Operadores de Comparação

São operadores que permitem comparar valores e retornar um valor booleano (True ou False).

  • Igualdade: ==
  • Diferente: !=
  • Maior que: >
  • Menor que: <
  • Maior ou igual a: >=
  • Menor ou igual a: <=
       a = 10
       b = 3


       igual = a == b   # False
       diferente = a != b   # True
       maior que = a > b   # True
       menor que = a < b   # False
       maior ou igual = a >= b   # True
       menor ou igual = a <= b   # False
Operadores Lógicos

São utilizados para combinar expressões condicionais e avaliar multiplas condições.

Isso em lógica de Python:

  • AND (and): Desvolve Tru se ambas foram condições verdadeiras
  • OR (or): Desvolve True se ao menos uma das condições for verdadeira
  • NOT (not): Inverte o valor da condiçoes, descolve tru se for falsa e false se for verdadeira 
      a = 10
      b = 3


     resultado_and = (a > 5) and (b < 5)   # True
     resultado_or = (a > 15) or (b < 5)   # True
     resultado_not = not (a > 5)   # False

Estruturas de Controle

São estruturas que permite ter o controle de fluxos de execução do programa. Como por exemplos podemos criar condições e loops. Essas estruturas nos permitem tomar decisões e repetir blocos de código segundo certas condições.

Estrutura Condicionais

A estrutura de condições lesas nos permite executar diferente blocos caso um deles não seja atendido. As condições mais utilizadas são if, if-else e if-elif-else.

if

O if utilizado quando um bloco de código e uma condição verdadeira.

       If condicao:
          # Bloco de código a ser executado se a condição for verdadeira instruções
     
        idade = 18
         if idade >= 18:
            print("Você é maior de idade.")
if-else

O if-else é utilizado quando queremos executar um bloco de código se a condição for verdadeira e outro bloco se a condição for falsa. 

        idade = 15

        if idade >= 18:
            print("Voce e maior de idade.")
        else:
            print("Voce e menor de idade.")
if-elif-else

O if-elif-else é utilizado quando queremos verificar múltiplas condições e executar diferentes blocos de código conforme a condição que for atendida. 

          if condicao1:

          # Bloco de código a executar se a condicao1 for verdadeira
          instruções

         elif condicao2:

         # Bloco de código a executar se a condicao2 for verdadeira
         instruções

         else:

         # Bloco de código a executar se nenhuma condição anterior for verdadeira
         instruções
       
          nota = 85
         if nota >= 90:
           print ("Excelente")

         elif nota >= 80:
           print ("Muito bom")

          elif nota >= 70:
            print ("Bom")

         else:
          print ("Precisa melhorar")

Loops

o loop nos permite executar varias condições repetidas vezes. e a mais comuns são " for " e " while ".

O loop for:

Ele e uma forma de lista para iterar sobre uma sequência de elementos.

           for variavel in sequencia:
             # Bloco de código a repetir instruções
         
           frutas = [ " maça, banana, mamão, laranja "]
          
           for fruta in frutas:
             print(fruta)
O loop while:

O loop while é utilizado quando queremos repetir um bloco de código enquanto uma condição for verdadeira. Podemos usar o exeplo do contador ele se repete enquanto a condição for verdadeira ate chegar o numero desejado.

              while condição:
               # Bloco de código a repetir instruções
          
             contador = 0
              while contador < 5:
                 print(contador)
                 contador += 1

Controle de loops

O python oferece algumas palavras-chave para controlar o fluxo dos loops, como o break e o continue.

break

E utilizado para sair prematuramente de um loop. Quando o break é executado, o loop é interrompido imediatamente.

               contador  = 0
                while true:
                    print(contador)
                    contador += 1
                    if contador == 5:
                        break
continue

A instrução continue é utilizada para pular o restante do bloco de código dentro de um loop e passar para a próxima iteração.

                for i in range(10):

                  if i % 2 == 0:
                    continue
                print(i)

Neste exemplo, o loop for itera sobre os números de 0 a 9 utilizando a função range(). Dentro do loop, verifica-se se o número é divisível por 2 utilizando o operador de módulo %. Se o número for divisível por 2 (ou seja, se for par), a instrução continue é executada, fazendo com que o restante do bloco de código seja pulado e passando para a próxima iteração do loop. Como resultado, apenas os números ímpares serão impressos.
